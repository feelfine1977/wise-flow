`<ProcessMap/>` reads a `describedLimit` below one as one. The Canvas map's
element list for assistive technology then always holds the element the
keyboard is on, and the table view pages its rows as at a limit of one. Up to
now a limit of 0 or less left the list empty while `aria-activedescendant`
named the keyboard position, and paged the table of a map with one element.
