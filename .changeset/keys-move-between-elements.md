The map's keyboard instructions say what the keys do: the arrow keys, Home
and End move between all elements with a box (activities, events, gateways,
notes and stage nodes), not only between activities. The string
`map.instructions` reads "Use the arrow keys to move between elements, …" in
English and "Pfeiltasten wechseln zwischen Elementen, …" in German; the keys
behave as before.
